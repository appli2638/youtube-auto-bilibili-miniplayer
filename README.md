# 📺 YouTube 捲動自動浮動小窗 (仿 Bilibili 效果)

一個專為 YouTube 看留言體驗打造的純淨、極致輕量功能插件。當你往下捲動網頁去閱讀網友留言或資訊欄時，影片播放器會**瞬間、無動畫延遲**地變為右下角的大懸浮視窗，往上捲回時自動無縫歸位。

---

### 🐒 這是什麼？如何安裝？
本專案為一個 **Tampermonkey（油猴）腳本插件**。不論你是使用 Chrome、Edge 還是 Firefox，都可以透過以下簡單兩步直接安裝使用：

1. **安裝瀏覽器外掛**：確保你的瀏覽器已安裝 [Tampermonkey (油猴)](https://tampermonkey.net) 擴充功能。
2. **一鍵安裝本插件**：點擊下方連結（或進入本專案的 `youtube-pip.user.js` 檔案點擊 "Raw"），油猴便會自動彈出安裝視窗：
   👉 [**點我直接一鍵安裝插件**](https://github.com) 
   *(⚠️ 請記得把上方網址中的「你的GitHub帳號」改成你真正的 GitHub 使用者名稱！)*

---

### ✨ 核心功能特色
* **瞬間現身 (0 延遲)**：取消任何華而不實的滑入動畫，原地登場，100% 根除畫面抖動與硬體卡頓。
* **Ctrl + 滾輪自由縮放**：滑鼠移到小窗上，**按住鍵盤 `Ctrl` 鍵並滾動滑鼠滾輪**，即可在 1000px 到 400px 之間平滑調整大小。
* **邊界硬鎖定**：放大到最大（1000px）或縮小到最小（400px）時會自動卡住，絕對不會循環錯亂。
* **低調紅框預覽與浮水印**：按住 `Ctrl` 時，右下角會自動顯現貼齊的半透明紅框與斜向雙頭指標 `⤡`。支援點擊穿透，不擋住 YouTube 原生控制鈕。
* **橫幅安全隔離**：實施精準的局部區域約束，完美保護 YouTube 頂部導覽列（ytd-masthead），橫幅 100% 絕對不會變透明。
* **原位排版收緊**：當小窗啟用時，原始影片位置的巨大黑色遮擋區塊會自動收緊，下方內容完美回彈。
